# Forest Clans

A small browser game inspired by the Warriors books. You make your own cat, join a clan, and grow from a kit into a warrior by completing tasks in a forest.

## How to play

1. Open `index.html` in a web browser. You don't need to install anything.
2. Make your cat: type a name, then pick its fur colour, eye colour, pattern and clan.
3. Press **Start**.

### Controls

| Key | Action |
| --- | --- |
| A / D or ← / → | Move |
| W, ↑ or Space | Jump |
| Shift, S or ↓ | Stalk (crouch and move slowly) |
| E | Action: pounce, fish or swipe |
| Esc | Stop fishing |

### Tasks

| Level | Task | Reward |
| --- | --- | --- |
| 1 (kit) | Hunt a squirrel. Stalk up to it without being heard, then pounce. | The cat grows |
| 2 (kit) | Go fishing at the river. Press E when the fish is in the gold zone, 3 times. | Become an apprentice (name ends in *-paw*) |
| 3 (apprentice) | Chase a rogue cat off your territory. | Become a warrior with a warrior name |

### Clans

| Clan | About | Perk |
| --- | --- | --- |
| ThunderClan | Forest hunters | Prey notices you less |
| RiverClan | Swimmers and fishers | Easier fishing, not slowed by water |
| WindClan | Fast runners | Runs faster |
| ShadowClan | Mysterious | Strikes harder in a fight |

## Files

- `index.html`, `style.css`, `script.js`: the game.
- `tests.html`: automatic tests. Open it in a browser; it plays through the game and lists PASS/FAIL for each check.
- `problem.md`, `spec.md`: what the game should be.
- `decision.md`, `handoff.md`: project notes.

## Hosting

The game is plain HTML, CSS and JavaScript, so it can be hosted for free on GitHub Pages.
